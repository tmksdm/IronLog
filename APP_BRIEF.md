# Описание приложения

## Результат для пользователя

Новая версия IronLog не применяется без согласия пользователя: сначала приложение показывает компактное предложение с номером версии, краткими изменениями и кнопками «Обновить» и «Пропустить».

## Целевая среда

- Платформы: веб-приложение/PWA и Android через Capacitor.
- Предполагаемый пользователь: текущий пользователь IronLog.
- Требования к автономной или сетевой работе: основной сценарий работает локально без сети; облачная копия выполняется в фоне.
- Важные ограничения конфиденциальности: данные тренировки не передаются новым сторонним сервисам.

## Сценарий минимальной версии

Если при автоматической сетевой проверке найдена более новая версия, приложение показывает предложение обновиться. Только нажатие «Обновить» очищает веб-кэш и перезагружает приложение; «Пропустить» закрывает предложение до следующего запуска.

## Сценарии приёмки

- [ ] Более новая версия вызывает компактное модальное окно поверх любого экрана, включая вход.
- [ ] В окне видны номер версии и не более двух главных изменений.
- [ ] Обновление применяется только после нажатия «Обновить».
- [ ] «Пропустить» закрывает окно, и оно не появляется снова для этой версии до следующего запуска.
- [ ] Отсутствие сети не мешает запуску и работе приложения.

## Ограничения качества

- Производительность: сохраняется текущий интервал проверки раз в 5 минут.
- Доступность: окно имеет семантику диалога, заголовок и кнопки с понятными названиями.
- Расход батареи или фоновая работа: проверка выполняется только при работающем приложении.
- Поддерживаемые версии ОС: без изменения текущих требований проекта.

## Явно не входит в минимальную версию

- Загрузка и установка нового APK из внешнего источника.
- Постоянное игнорирование выбранной версии между запусками.
- Принудительное обновление без возможности пропустить.

## Команды проверки

- Сборка: `npm run build`
- Тесты: `npm test`.
- Статический анализ и проверка типов: `npm run lint`; проверка типов входит в сборку.
- Запуск или создание пакета: `npm run build:android`

## Открытые решения и допущения

- «Пропустить» действует до следующего запуска приложения, чтобы обновление не было потеряно навсегда случайным нажатием.
- В окне показываются первые два пункта описания релиза; полный список остаётся в разделе версии в настройках.
