# Описание приложения

## Результат для пользователя

Пользователь сможет провести отдельную тренировку со скакалкой по таймеру 1:15, сохранить число прыжков и увидеть запись в истории.

## Целевая среда

- Платформы: веб-приложение/PWA и Android через Capacitor.
- Предполагаемый пользователь: текущий пользователь IronLog.
- Требования к автономной или сетевой работе: основной сценарий работает локально без сети; облачная копия выполняется в фоне.
- Важные ограничения конфиденциальности: данные тренировки не передаются новым сторонним сервисам.

## Сценарий минимальной версии

При открытом главном экране, когда пользователь выбирает «Скакалка», запускает таймер, вводит число прыжков и нажимает «Сохранить», тогда отдельная запись сохраняется локально и отображается в отдельном разделе истории.

## Сценарии приёмки

- [ ] На главном экране «Скакалка», «Турник» и «Бег» находятся в одном ряду.
- [ ] Таймер можно запустить, остановить и запустить заново.
- [ ] Нулевой результат сохранить нельзя; положительный результат сохраняется один раз.
- [ ] Запись скакалки не отображается как пробежка и доступна в отдельном фильтре истории.
- [ ] Сохранение работает без сети; ошибка фоновой синхронизации не блокирует пользователя.

## Ограничения качества

- Производительность: таймер не должен создавать более одного активного интервала.
- Доступность: интерактивные элементы имеют понятные подписи, числовой ввод использует цифровую клавиатуру.
- Расход батареи или фоновая работа: фонового опроса и постоянной фоновой работы нет.
- Поддерживаемые версии ОС: без изменения текущих требований проекта.

## Явно не входит в минимальную версию

- Автоматический подсчёт прыжков датчиками или камерой.
- Программа прогрессии для скакалки.
- Восстановление незавершённого таймера после закрытия приложения.

## Команды проверки

- Сборка: `npm run build`
- Тесты: отдельной команды тестов в проекте нет.
- Статический анализ и проверка типов: `npm run lint`; проверка типов входит в сборку.
- Запуск или создание пакета: `npm run build:android`

## Открытые решения и допущения

- Используется прежняя длительность упражнения — 1 минута 15 секунд.
- Число прыжков пользователь вводит вручную после подхода.
