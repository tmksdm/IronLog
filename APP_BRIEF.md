# Описание приложения

## Результат для пользователя

Новая версия веб-приложения IronLog остаётся в ожидании и заменяет текущую только после подтверждения пользователя в окне обновления.

## Целевая среда

- Платформы: веб-приложение/PWA и Android через Capacitor.
- Предполагаемый пользователь: текущий пользователь IronLog.
- Требования к автономной работе: установленная PWA должна запускаться из кэша без сети.
- Облачная работа: не относится к механизму обновления.

## Сценарий минимальной версии

Когда опубликована новая версия, service worker загружает её файлы в отдельный кэш, не активируя их. Приложение показывает номер версии и изменения; «Пропустить» сохраняет текущую версию, а «Обновить» активирует новый кэш и перезагружает интерфейс.

## Сценарии приёмки

- [ ] Текущая PWA продолжает загружаться из прежнего кэша после публикации новой версии.
- [ ] Новая версия активируется только после нажатия «Обновить».
- [ ] «Пропустить» не активирует ожидающий service worker.
- [ ] После подтверждения новый worker получает управление и только затем страница перезагружается.
- [ ] `version.json` всегда проверяется по сети и не блокируется кэшем приложения.
- [x] В карточке упражнения активной тренировки справа от текущего веса и счётчика подходов показаны повторы рабочих подходов из прошлой тренировки в формате `прошл.: 7/6/6`.
- [x] Подсказка берёт только непропущенные рабочие подходы из одной последней завершённой тренировки и не показывается при отсутствии истории.
- [x] Редактируемый вес до тренировки находится в верхней строке шапки и не уменьшает высоту прокручиваемой области отдельной строкой.

## Ограничения качества

- Сбой сети не мешает запуску уже сохранённой версии приложения.
- Новый кэш не удаляет текущий до явного подтверждения.
- Диалог обновления остаётся доступным поверх любого экрана.
- История прошлых подходов читается из локальной SQLite и доступна без сети.
- Компактная кнопка веса сохраняет доступное название действия для экранного диктора.

## Явно не входит в минимальную версию

- Самообновление нативного APK: этот механизм относится к веб/PWA-сборке.
- Установка исправления 0.26.1 с удержанием 0.26.0: в 0.26.0 service worker ещё отсутствует.

## Команды проверки

- `npm run lint`
- `npm test`
- `npm run build`
- `npm run build:ghpages`
- `npm run build:android`
- `npm audit --audit-level=high`

## Открытые решения и допущения

- Выпуск 0.26.1 один раз устанавливает service worker; управляемое подтверждение действует для последующих PWA-релизов.
- Нажатие «Пропустить» действует до следующего запуска приложения.
