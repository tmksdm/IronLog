# Описание приложения

## Результат для пользователя

IronLog сохраняет ход тренировки и показывает точное время отдыха, даже если экран был выключен или приложение временно находилось в фоне.

## Целевая среда

- Платформы: веб-приложение/PWA и Android через Capacitor.
- Предполагаемый пользователь: текущий пользователь IronLog.
- Требования к автономной работе: установленная PWA должна запускаться из кэша без сети.
- Облачная работа: не относится к механизму обновления.

## Сценарий минимальной версии

Во время силовой тренировки пользователь нажимает на название упражнения, вводит исправленный вариант и сохраняет его. Новое название сразу появляется в активной тренировке, истории, статистике и редакторе упражнений.

После подхода пользователь может выключить экран или перейти в другое приложение. При возвращении таймер показывает остаток по реальному времени, а завершение отдыха сопровождается короткой плашкой только внутри IronLog.

## Сценарии приёмки

- [ ] Новая версия активируется без действий внутри приложения.
- [ ] Получение исправления не зависит от работоспособности текущего экрана.
- [ ] После смены worker страница автоматически перезагружается.
- [x] После смены worker открытые окна перезагружаются самим worker, даже если JavaScript старой страницы не работает.
- [x] Предыдущий кэш сохраняется как страховка для ещё не перезагруженного окна; более старые кэши удаляются после перехода окон.
- [ ] `version.json` всегда проверяется по сети и не блокируется кэшем приложения.
- [x] Название упражнения в активной тренировке доступно как кнопка редактирования с понятным названием для экранного диктора; длинный текст показывается полностью и переносится без многоточия.
- [x] Пустое название не сохраняется, а ошибка локальной записи не меняет название на текущем экране.
- [x] Исправленное название сохраняется в SQLite, в снимке активной тренировки и отправляется в облачный бэкап существующей фоновой синхронизацией.
- [x] В карточке упражнения активной тренировки справа от текущего веса и счётчика подходов показаны вес и повторы рабочих подходов из прошлой тренировки в формате `прошл.: 50, 7/7/6`.
- [x] Подсказка берёт только непропущенные рабочие подходы из одной последней завершённой тренировки и не показывается при отсутствии истории.
- [x] Редактируемый вес до тренировки находится в верхней строке шапки и не уменьшает высоту прокручиваемой области отдельной строкой.
- [x] В статистике есть отдельная вкладка скакалки со средним количеством прыжков за тренировку по месяцам и годам; среднее округляется вниз до целого.
- [x] В статистике подтягиваний показано округлённое вниз среднее число повторов за тренировку, рассчитанное по итогам всех тренировок периода; количество тренировок остаётся видимым.
- [x] Таймеры отдыха силовой тренировки и турника вычисляют остаток по абсолютному времени и не замедляются при приостановке приложения.
- [x] После окончания отдыха внутри IronLog на 2,5 секунды появляется плашка; системные уведомления и разрешения не используются.
- [x] Точное время окончания отдыха сохраняется в снимках активной силовой тренировки и турника.

## Ограничения качества

- Сбой сети не мешает запуску уже сохранённой версии приложения.
- Новый кэш полностью устанавливается до активации.
- Обновление не очищает SQLite, IndexedDB, авторизацию или другие пользовательские данные.
- История прошлых подходов читается из локальной SQLite и доступна без сети.
- Компактная кнопка веса сохраняет доступное название действия для экранного диктора.
- Изменение названия сначала сохраняется локально и не зависит от доступности Supabase.
- Фоновое ограничение JavaScript не изменяет фактическую длительность отдыха; при возвращении интерфейс немедленно догоняет реальное время.

## Явно не входит в минимальную версию

- Самообновление нативного APK: этот механизм относится к веб/PWA-сборке.

## Открытые решения и допущения

- Активация может перезагрузить открытую PWA; активная силовая тренировка перед этим сохраняется локально и предлагается к восстановлению.
